# Bee Researcher v2.43.0

## Telegram channels and publishing bot

- The schedule and channel page now has a persistent project-level Telegram section; it no longer depends on a dynamically injected card.
- It lists every configured destination channel with its numeric ID, role, feedback-button behavior, configuration source and readiness.
- Bot display name, username, numeric ID and each channel ID are editable in the backoffice.
- The bot token remains server-side only and is never displayed or persisted through the backoffice.
