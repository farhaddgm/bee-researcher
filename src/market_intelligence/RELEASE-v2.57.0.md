# Bee Researcher v2.57.0

## تغییرات

- رفع نمایش پایدار برچسب «خروج» در زبان فارسی و حفظ آیکن خروج.
- اعمال سقف پیش‌فرض ۱۰ رسانه برای هر پروژه با کنترل سمت سرور.
- اضافه شدن منوی «تنظیمات» مخصوص مالک برای تعیین سقف‌های رسانه، موضوع، پنجره تازگی، انتشار هر نوبت، بیزینس و پروژه.
- محدودیت‌های جدید هنگام ساخت رسانه، موضوع، بیزینس و پروژه اعمال می‌شوند و کاهش سقف، تنظیمات اجرایی پروژه را نیز همگام می‌کند.

## بررسی

- تست‌های واحد و API در کانتینر اجرا می‌شوند.
- سلامت سرویس پس از deploy با endpoint سلامت بررسی می‌شود.
