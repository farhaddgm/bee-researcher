# Bee Researcher v2.46.0

## Feedback dashboard and account lifecycle

- کارت‌های بازخورد اکنون تعداد کل سیگنال، مرتبط و نامرتبط را از گزارش همان پروژه با fallback امن به جدول کاربران محاسبه می‌کنند؛ API نیز نام‌های سازگار `related/unrelated` را برمی‌گرداند.
- مدیر سیستم می‌تواند کاربر را همراه با نشست‌ها و عضویت‌های پروژه حذف کند.
- حذف حساب جاری و حذف آخرین مدیر فعال مسدود می‌شود تا دسترسی مدیریتی از بین نرود.
- حذف کاربر در لاگ مدیریتی ثبت می‌شود و هیچ رمز یا secretی به رابط کاربری بازگردانده نمی‌شود.
- مسیرهای bootstrap قدیمی نمای کلی که KPIها را با رقم لاتین بازنویسی می‌کردند حذف شدند؛ مقدارها فقط با زبان انتخاب‌شده و یک مسیر رندر پایدار نمایش داده می‌شوند.
