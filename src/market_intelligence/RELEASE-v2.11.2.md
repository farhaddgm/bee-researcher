# Bee Researcher v2.11.2

## تکمیل scope در بک‌آفیس

- موضوعات با workspace انتخاب‌شده و کنترل دسترسی همان workspace خوانده می‌شوند.
- گزارش هفتگی از workspace انتخاب‌شده اجرا می‌شود.
- wrapper درخواست‌های UI برای metrics، منابع، خبرها، موضوعات و گزارش را با `assistant_id` محدود می‌کند.
- هیچ secret یا داده workspace دیگر به UI انتخاب‌شده اضافه نمی‌شود.
