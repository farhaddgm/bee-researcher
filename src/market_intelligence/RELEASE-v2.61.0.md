# Release v2.61.0

## سقف انتشار در هر نوبت

- انتشار زمان‌بندی‌شده به‌ازای هر پروژه و هر slot یک claim یکتا دارد؛ polling تکراری همان دقیقه نمی‌تواند batch دیگری منتشر کند.
- سقف انتشار همچنان از `max_items_per_run` پروژه خوانده می‌شود و در همان نوبت اعمال می‌شود.
- فقط پیش‌نویس‌های ساخته‌شده در ساعت جاری برای slot جاری واجد شرایط هستند؛ پیش‌نویس‌های باقی‌مانده از slotهای از دست‌رفته به نوبت بعد منتقل نمی‌شوند و فقط از مسیر بررسی/انتشار دستی قابل اقدام‌اند.
- جمع‌آوری و تحلیل ساعتی از سقف انتشار جدا باقی می‌ماند و سقف پردازش روزانه ۱۰۰۰ خبر برای هر پروژه حفظ شده است.
- تست‌های جدید برای عدم catch-up و claim نوبت اضافه شد.
