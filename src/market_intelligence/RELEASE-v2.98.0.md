# Bee CFO v2.98.0

## Append-only channel extensions

- Keeps the approved price, media-title, and horizon cards unchanged and in
  the same order.
- Adds bounded follow-up cards only after those cards and only when their data
  gate passes: evidence-backed factors, model estimates, conditional
  scenarios, quality/coverage, and follow-up events or checks.
- Retains the no-call rule for numerical forecasts and does not let media
  outlooks become a price target.
- Adds regression coverage for the immutable core cards, source-link scope,
  bounded message length, and live-quote-aware quality reporting.
