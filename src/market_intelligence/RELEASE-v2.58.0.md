# Bee Researcher v2.58.0

## تغییرات

- MI-086: دکمهٔ پیشنهاد رسانه اکنون یک کلیدواژه می‌گیرد و حداکثر پنج رسانهٔ تخصصی و معتبر را با توضیح کوتاه و وب‌سایت پیشنهاد می‌دهد؛ اطلاعات فنی فقط بعد از تأیید مالک تکمیل و ثبت می‌شود.
- MI-087: کاهش سقف‌های پروژه به‌صورت کنترل‌شده اعمال می‌شود. رسانه‌های اضافی غیرفعال می‌شوند، runtime به سقف جدید همگام می‌شود و فقط در صورت عبور مقدار فعلی از سقف جدید، اعلان صندوق پیام برای کاربران مجاز ایجاد می‌شود.
- متن دکمهٔ تنظیمات سقف به «ثبت» تغییر کرد و فاصلهٔ بالایی آن اصلاح شد.
- API صندوق پیام برای مشاهده و علامت‌گذاری اعلان‌ها اضافه شد.

## بررسی

- تست‌های واحد و API در کانتینر اجرا می‌شوند.
- سلامت سرویس پس از deploy با endpoint سلامت بررسی می‌شود.
