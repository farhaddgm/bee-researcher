# Release v2.59.12

## تنظیمات پروژه — رفع خطای بارگذاری و اعداد فارسی

- خطای صفحهٔ تنظیمات که هنگام بارگذاری سقف‌ها به تابعی خارج از scope ارجاع می‌داد رفع شد.
- مقادیر فرم تنظیمات در فارسی با رقم فارسی نمایش داده می‌شوند.
- هنگام ذخیره، رقم‌های فارسی بدون خطای اعتبارسنجی به عدد لاتین تبدیل می‌شوند و پاسخ سرور دوباره به رقم فارسی نمایش داده می‌شود.
- ورودی نامعتبر پیام واضح نشان می‌دهد و درخواست ناقص به API ارسال نمی‌شود.

تست: suite کامل اپلیکیشن و تست رگرسیون UI تنظیمات.
