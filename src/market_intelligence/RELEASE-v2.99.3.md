# Bee CFO v2.99.3

Manual-pilot readiness is now distinct from automatic publication readiness.

- An explicitly requested, controlled Telegram delivery can be audited without
  schedule slots or an active scheduler.
- Automatic publication still requires an active profile and configured slots.
- Readiness is pure, explainable, and fail-closed for missing market, source,
  watch, Telegram, or output-contract requirements.
- No Bee Researcher table, queue, configuration, or delivery path is changed.
