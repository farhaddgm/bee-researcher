# Bee Researcher v3.29.4 — User reader navigation and settings polish

- Matched the User portal account control to the Admin sidebar pattern: the
  signed-in identity is a footer trigger and sign-out is available from its
  menu instead of as a permanent navigation row.
- Added a dedicated Bee mark for the collapsed sidebar so the full lockup is
  never cropped.
- Expanded feed loading skeletons to reserve a complete card grid while
  assistants and publications load.
- Moved the News reader explanation behind a compact, keyboard-accessible
  information button.
- Simplified Reader settings by removing nested field cards, adding concise
  help tooltips for all nine settings, moving keyboard shortcuts below the
  title, and giving browser notifications a clear switch and description.
