## MI-036 — unified backoffice sizing

- Introduced shared control-size tokens for buttons, inputs, selects, cards and action groups.

- Removed table-action crowding and inconsistent button margins.
- Kept the 7×24 schedule grid compact while aligning it with the same control rhythm.
- Added mobile-specific rules so controls remain tappable without oversized cards or broken wrapping.
- No API, data, permission or publishing behavior changed in this iteration.
