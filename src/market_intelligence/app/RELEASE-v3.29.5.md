# Bee Researcher v3.29.5 — Admin control consistency and workspace reliability

- Reworked the Support surface with a resilient two-column layout, queue
  filters, responsive ticket cards, owner triage controls and consistent empty
  and error states.
- Added a shared button/control pattern and removed obsolete page context,
  duplicate actions, evidence actions and the old content-edit action.
- Added a direct, validated media-source form with optional smart URL drafting;
  source IDs remain server-generated and a source can be probed without
  publishing.
- Assistants can now be created without a business profile; the pipeline uses a
  neutral general-market context until a business profile is added.
