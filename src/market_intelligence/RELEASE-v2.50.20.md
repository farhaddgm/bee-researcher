# Release v2.50.20

## Professional icon system

- Benchmarked Lucide, Heroicons and Phosphor for consistency, visual weight, customization and runtime footprint.
- Selected Lucide-style outline icons: the set is open source, has a broad interface vocabulary, and uses lightweight scalable SVGs.
- Added a small inline SVG icon registry so the back office does not depend on a remote CDN at runtime.
- Replaced symbolic sidebar glyphs and utility controls with consistent icons for navigation, search, notifications, refresh, menu and sign-out.
- Icons inherit the existing theme color, remain crisp at RTL/LTR layouts, and are marked decorative for screen readers unless a label is provided.
