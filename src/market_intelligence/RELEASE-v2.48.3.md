# Release v2.48.3

## اصلاح نام حساب در هدر

- هدر پس از ورود، نام حساب واقعی پاسخ `/admin/api/me` را نمایش می‌دهد.
- پاسخ‌های احراز هویت قدیمی که پس از ورود/خروج سریع برمی‌گردند، دیگر نمی‌توانند نام کاربر قبلی را روی هدر بنویسند.
- مقدار اولیه هدر دیگر نام ثابت `admin` نیست و تا زمان احراز هویت، خط تیره نمایش داده می‌شود.
