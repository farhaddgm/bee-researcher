# Bee CFO Telegram destination sync v2.71.0

## تغییر اصلی

- مقصد عددی تلگرام از قرارداد secret-free شیت به تنظیمات workspace مستقل Bee CFO همگام می‌شود.
- workspace جدید دیگر برای readiness یا تحویل گزارش به مقصد پروژهٔ دیگری fallback نمی‌کند.
- توکن ربات همچنان فقط از deployment secret خوانده می‌شود و در شیت، workspace config یا لاگ ذخیره نمی‌شود.

## اعتبارسنجی

- تست قرارداد مقصد workspace اضافه شد.
- تست‌های Bee CFO، گیت انتشار، تحلیل و جداسازی زیرساخت باید قبل از deploy موفق باشند.
- readiness تلگرام با `getMe` و مجوزهای مقصد به‌صورت خواندنی بررسی می‌شود؛ ارسال گزارش واقعی همچنان پس از فعال‌سازی source/watch انجام می‌شود.
