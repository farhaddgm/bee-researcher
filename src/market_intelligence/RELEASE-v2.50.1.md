# Bee Researcher v2.50.1

## Project-scoped channel settings

- New projects start with an empty allowed-feedback-user list and cannot inherit actors from another project.
- The feedback username placeholder is now `farhaad`.
- Persian mode displays the per-run news limit using Persian digits while saving normalized numeric values.
- Schedule rows and hour headers are clickable bulk selectors: click a day to toggle all 24 hours, or an hour header to toggle that hour across all seven days.
