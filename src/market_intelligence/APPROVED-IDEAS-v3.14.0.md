# Approved ideas delivered in v3.14.0

این بسته شش ایده‌ی تأییدشده‌ی باز را بدون تغییر در اسکیمای پایگاه‌داده و با
استفاده از داده‌های واقعی پروژه پیاده‌سازی می‌کند.

- MI-210 / I-061: گردش بررسی `draft → review → approved/rejected` در `audit` هر انتشار ثبت می‌شود؛ تأیید نهایی فقط برای مالک یا مدیر پروژه است و زمان‌بندی فقط موارد تأییدشده را منتشر می‌کند.
- MI-211 / I-062: زنجیره‌ی شواهد از امتیاز موضوع، مؤلفه‌های کیفیت، facts، citations، نسخه‌ی مدل، زمان دریافت و خبرهای هم‌پوشان ساخته می‌شود؛ متن حدسی به‌عنوان واقعیت نمایش داده نمی‌شود.
- MI-212 / I-063: سلامت هر رسانه شامل تأخیر آخرین اجرا، تعداد خطاهای ۳۰ روز، تازگی دریافت و وضعیت آخرین run است؛ رکوردها از `source_fetch_runs` خوانده می‌شوند.
- MI-213 / I-065: پیش‌نمایش تنظیمات، تفاوت قبل/بعد و ظرفیت انتشار روزانه را بدون نوشتن تنظیمات و بدون تماس تلگرام نشان می‌دهد.
- MI-214 / I-067: clone آزمایشی با برچسب Sandbox، بدون مقصد و secret، در وضعیت testing ساخته می‌شود و ارسال واقعی برای آن fail-closed است.
- MI-215 / I-068: لینک گزارش یک‌بارنمایش با token هش‌شده، محدوده‌ی پروژه، تاریخ انقضا، لغو، شمارش مشاهده و خروجی فقط‌خواندنی فراهم شده است.

مسیرهای API و تست‌های قرارداد در `app/main.py`، `app/admin.py`،
`app/insights.py` و `tests/test_mi214_features.py` قرار دارند.
