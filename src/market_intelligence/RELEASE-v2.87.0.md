# Bee Researcher — Release v2.87.0

این نسخه چهار مورد تأییدشدهٔ بازِ News List را تکمیل می‌کند: MI-159 تا MI-162.

## تغییرات

- **MI-159 — تأیید دومرحله‌ای انتشار:** دکمهٔ تأیید از drawer جزئیات، ابتدا پنجرهٔ تأیید رسمی باز می‌کند؛ فقط پس از تأیید، انتشار انجام می‌شود و drawer و پنجره بسته می‌شوند.
- **MI-160 — امتیاز ارتباط:** ستون «امتیاز ارتباط» به جدول اصلی News List بازگردانده شد و مقدار واقعی relevance score نمایش داده می‌شود.
- **MI-161 — صفحه‌بندی:** نمایش خبرها به صفحه‌های ۲۰تایی با شمارهٔ صفحه، قبلی و بعدی تغییر کرد؛ Load more حذف شد.
- **MI-162 — متن راهنمای اضافی:** عبارت راهنمای «Needs review — open details to approve» از ردیف‌های جدول حذف شد؛ وضعیت خبر همچنان نمایش داده می‌شود.

## کنترل‌ها

- انتشار همچنان فقط از drawer و با تأیید دومرحله‌ای انجام می‌شود.
- ستون امتیاز فقط مقدار API واقعی را نشان می‌دهد و مقدار ساختگی تولید نمی‌شود.
- داده‌های خارج از صفحهٔ جاری حفظ می‌شوند و صفحه‌بندی فقط در لایهٔ نمایش اعمال شده است.

## اعتبارسنجی

- `py_compile` برای Admin، Main و UI موفق است.
- تست pipeline و smoke test رابط News List پس از deploy اجرا می‌شود.
