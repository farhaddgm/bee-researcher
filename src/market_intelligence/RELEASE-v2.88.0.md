# Bee Researcher — Release v2.88.0

این نسخه گام تأییدشدهٔ «دفاع در برابر prompt injection منبع» (MI-163) را تکمیل می‌کند.

## تغییرات

- عنوان و متن خبرهای بازیابی‌شده از وب قبل از ارسال به مدل، دادهٔ غیرقابل‌اعتماد و غیر‌دستوری در نظر گرفته می‌شوند.
- الگوهای پرخطر فارسی و انگلیسی شناسایی می‌شوند؛ خط مشکوک از ورودی مدل حذف می‌شود و flag ایمنی ثبت می‌گردد، بدون حذف کل مقاله.
- در prompt سیستم صریحاً از اجرای دستورهای منبع، افشای system/developer prompt و افشای secret جلوگیری می‌شود.
- در تحلیل fallback و خروجی تحلیل نیز یادداشت قابل‌مرور ایمنی ثبت می‌شود تا منبع مشکوک برای اپراتور قابل تشخیص باشد.

## کنترل‌ها

- دامنهٔ این guard فقط محتوای خارجی مقاله است و به پروفایل کسب‌وکار، موضوعات تأییدشده یا تنظیمات مالک دست نمی‌زند.
- هیچ secret یا متن prompt داخلی در Google Sheet یا خروجی تحلیل ذخیره نمی‌شود.

## اعتبارسنجی

- `py_compile` برای مسیر OpenAI، pipeline و تست‌ها موفق است.
- تست واحد redaction برای الگوهای فارسی/انگلیسی اضافه شده و suite pipeline پیش از deploy اجرا می‌شود.
