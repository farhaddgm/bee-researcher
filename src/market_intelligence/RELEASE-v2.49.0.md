# Release v2.49.0

## ماتریس دسترسی و جداسازی پروژه‌ها

- دسترسی سراسری فقط برای مالک باقی ماند؛ نقش ادمین کل اکنون بدون تخصیص صریح پروژه، هیچ پروژه‌ای را نمی‌بیند.
- فهرست دستیارها، بیزینس‌ها، رسانه‌ها، موضوعات، کانال‌ها، زمان‌بندی، خبرها و گزارش‌ها با عضویت پروژه فیلتر می‌شود.
- ویرایشگر و مشاهده‌گر به داده‌ها و endpointهای پروژه‌های خارج از تخصیص دسترسی ندارند.
- مدیریت کاربران و نقش‌ها برای ادمین کل به پروژه‌های تخصیص‌یافته محدود شد و تخصیص پروژه برای نقش ادمین در رابط کاربری فعال شد.
- تست‌های cross-workspace و قواعد deny-by-default به قرارداد امنیتی بک‌آفیس اضافه شدند.
