# Bee Researcher — v3.14.0

## خروجی

- شش ایده‌ی تأییدشده‌ی باز از شیت پیشنهادها به MI-210 تا MI-215 در رودمپ منتقل و تکمیل شد.
- گردش تأیید انتشار، پنل توضیح امتیاز و شواهد، متریک تازگی/تأخیر رسانه، پیش‌نمایش dry-run تنظیمات، Sandbox fail-closed و لینک گزارش محدود/منقضی‌شونده اضافه شد.
- بک‌آفیس برای صف خبر، شواهد و پیش‌نمایش تنظیمات کنترل‌های قابل استفاده دارد؛ token لینک گزارش فقط یک‌بار برگردانده می‌شود و در پایگاه‌داده فقط hash ذخیره می‌شود.
- شمارنده‌ی CSP اکنون فقط attribute واقعی HTML را می‌سنجد و انتساب DOM در JavaScript را به‌اشتباه inline حساب نمی‌کند.

## بررسی و استقرار

- build ایمیج `ai-market-intelligence:3.14.0` موفق شد.
- تست کامل کانتینری: **۲۶۸ تست موفق**.
- production با همین ایمیج فعال است؛ `health=healthy`، وابستگی‌های PostgreSQL و Redis سالم، و `/admin` با HTTP 200 پاسخ می‌دهد.
- Sandbox و لینک گزارش محدود به‌صورت fail-closed و پروژه‌محور هستند؛ هیچ secret یا مقصد Telegram از clone آزمایشی منتقل نمی‌شود.
