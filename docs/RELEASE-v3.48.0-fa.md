# Bee Researcher 3.48.0

مالک می‌تواند سقف مجموع توکن ورودی/خروجی را برای ۶ ساعت شناور، روز تهران، ماه میلادی تهران و کل تاریخچه تنظیم کند. پیش‌فرض عمومی، پیش‌فرض هر پروژه و استثنای حساب در پروژه وجود دارد. همهٔ کاربران Reader گزارش خصوصی مصرف، سقف، مانده، رزرو/برآورد و تاریخچه را در تنظیمات ← گزارش دارند.

کنترل قبل از ارسال به ارائه‌دهنده و با رزرو اتمی انجام می‌شود. مصرف واقعی از رزرو جداست؛ پاک‌کردن گفتگو سهمیه را بازنمی‌گرداند. نام کاربری یا نقش مدیر، دسترسی تغییر سقف نمی‌دهد؛ فقط ایمیل مالک تنظیم‌شده مجاز است.

schema افزایشی 0051_token_quotas پس از بکاپ خصوصی Researcher منتشر می‌شود. شمارنده‌ها و تنظیمات هنگام rollback حفظ می‌شوند و نویسندهٔ قدیمی هم توسط trigger سازگار به دفتر مصرف وصل می‌شود. اعداد سقف اولیه نامحدود هستند؛ مجوزها، رمزها، رضایت کسب‌وکار و تنظیمات سرویس‌های دیگر تغییر نمی‌کنند.

اعتبارسنجی شامل آزمون‌های واحد، SQL واقعی برای بازه‌ها/هم‌زمانی/حذف/دسترسی، مرورگر احرازشده در هشت زبان و چهار عرض، دسترس‌پذیری، دروازهٔ کامل محلی و دروازه‌های الزامی CI است. آزمون‌ها فقط با حساب‌ها و ارائه‌دهندگان مصنوعی انجام می‌شوند.
