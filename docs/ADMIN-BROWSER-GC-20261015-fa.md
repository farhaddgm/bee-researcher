# تشخیص خطای متناوب بازخوانی در تست مرورگر

در CI نهایی نسخهٔ ۳٫۵۴٫۰، آزمون جدول خبر با پیام عمومی Playwright دربارهٔ
ازبین‌رفتن context شکست خورد. سیاست انتشار آن را نادیده نگرفت و سرور روی
۳٫۵۲٫۰ باقی ماند. بیست ورود مستقل معمولی نیز برای ردکردن این خطا کافی نبود.

با ثبت محدود خطای پروتکل و اجرای `HeapProfiler.collectGarbage`، خطای خام
`Protocol error (Runtime.callFunctionOn): Promise was collected` در محیط
ایزوله بازتولید شد. Playwright 1.55.1 در `crExecutionContext.rewriteError`
خطاهای پروتکل را به پیام عمومی navigation تبدیل می‌کند؛ بنابراین این پیام
به‌تنهایی اثبات reload یا خرابی نشست نیست.

در helper مشترک آزمون‌ها، هر اجرای `loadAll` تا پایان به شناسه‌ای تصادفی در
همان document متصل است. آزمون وضعیت واقعی پایان/شکست را انتظار می‌کشد و سپس
reference را پاک می‌کند. retry، تأخیر دلخواه، پذیرش خطا یا دستکاری دادهٔ محصول
اضافه نشده است. شکست واقعی درخواست، timeout و تغییر document همچنان تست را
ناموفق می‌کنند. آزمون خبر سه بار جمع‌آوری اجباری حافظه را اعمال می‌کند.

هیچ تنظیم امنیتی، نشست کاربر، دادهٔ واقعی یا نسخهٔ Playwright برای عبور از
تست تغییر نمی‌کند. این اصلاح زیرساخت تست است، نه شاهد بروز reload برای کاربر.
