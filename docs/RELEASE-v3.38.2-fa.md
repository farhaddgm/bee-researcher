# نسخهٔ ۳.۳۸.۲ — اصلاح نهایی شبکهٔ دستیارها

بازبینی تصویریِ سناریوی دارای چند پروژهٔ حذف‌شده نشان داد بخش بازیابی داخل شبکهٔ دستیارها قرار می‌گیرد و کارت‌های فعال را هم‌قدِ کل فهرست بازیابی می‌کند. اکنون بخش بازیابی هم‌سطح شبکه است، کارت حذف‌شده دوباره در فهرست فعال نمایش داده نمی‌شود و بازترسیم یا تغییر نقش، بخش قدیمی را تکرار یا باقی نمی‌گذارد.

آزمون مرورگری با ۲۰ پروژهٔ حذف‌شده، بازترسیم تکراری، کنترل ارتفاع کارت فعال و تغییر نقش اضافه شد. شمارهٔ پیش‌فرض سرویس نیز از فایل VERSION خوانده می‌شود تا با نسخهٔ بسته اختلاف نداشته باشد. تمام اصلاحات و گیت‌های نسخهٔ ۳.۳۸.۱ حفظ شده‌اند؛ تغییر schema، حذف داده، تنظیمات پروژه یا نشست انجام نمی‌شود.
