# Bee Researcher 3.42.0 — مطالعهٔ خبر و گفت‌وگوی موقت

## رفتار محصول

- متن خبر در کارت، پنجره و لینک مستقیم User دیگر بخش‌های آمادهٔ فرصت و ریسک را نشان نمی‌دهد. نسخهٔ منتشرشدهٔ تلگرام و اطلاعات Admin تغییر نمی‌کنند.
- دکمه‌های «فرصت‌ها» و «ریسک‌ها» فقط با کلیک کاربر، تحلیل مفصلِ مستند به همین خبر را با برند، مدل و زبان انتخاب‌شده درخواست می‌کنند. درخواست مشمول همان سهمیه و بودجهٔ چت است؛ بازکردن خبر درخواست پولی ایجاد نمی‌کند.
- تحلیل و پرسش‌های بعدی در یک گفت‌وگو ادامه می‌یابند. تغییر برند، گفت‌وگوی تازه آغاز می‌کند و متن قبلی به برند جدید منتقل نمی‌شود.
- زمینهٔ خبر، محدودیت متن و سقف درخواست روزانه در راهنمای `i` کنار عنوان گفت‌وگو قرار دارند. متن راهنمای آغاز گفت‌وگو در حالت خالیِ همان بخش قرار دارد. انتخاب پاراگراف و انتخاب تاریخچه از UI حذف شده‌اند.
- با بستن پنجره، کلیک بیرون، Escape، ترک صفحه یا خروج، متن‌ها و پیش‌نویس از وضعیت مرورگر پاک می‌شوند و درخواست پاک‌سازی سمت سرور ارسال می‌شود. بازکردن مجدد، چت قبلی را بازیابی نمی‌کند.

## قرارداد پاک‌سازی و محدودیت‌های آن

- پنجره پیش از اولین درخواست، یک UUID تصادفی مشخص می‌کند. بستن پنجره برای همان UUID یک نشانگر بدون محتوا ثبت می‌کند؛ پاسخ دیررسِ ایجاد گفت‌وگو نمی‌تواند آن را زنده کند.
- ایجاد، ارسال، heartbeat و پاک‌سازی با یک قفل تراکنشی هماهنگ‌اند. متن سؤال، پاسخ، استنادها و snapshot خبر پاک و کار در حال اجرا لغو می‌شود؛ worker اجازهٔ بازنوشتن محتوای پاک‌شده را ندارد.
- برای crash، قطع شبکه، بسته‌شدن tab و تحویل‌نشدن close، گفت‌وگوی باز lease دو دقیقه‌ای دارد. heartbeat هر ۲۰ ثانیه آن را تمدید می‌کند، نه نشست ورود کاربر را. پاک‌سازی دوره‌ای هر ۳۰ ثانیه اجرا می‌شود؛ در حالت عادی محتوای رهاشده حداکثر تا حدود ۱۵۰ ثانیه پاک می‌شود. اختلال خود پایگاه داده یا worker می‌تواند این زمان را افزایش دهد و دسترسی به lease منقضی‌شده در API بسته است.
- سطرهای بدون متنِ مصرف برای جلوگیری از دورزدن سهمیه، بودجه و پرداخت تکراری حفظ می‌شوند. درخواست صف‌شده‌ای که هنوز اجرا نشده هزینهٔ واقعی صفر دارد؛ درخواست در حال اجرا تا تعیین مصرف واقعی، رزرو محافظه‌کارانهٔ خود را حفظ می‌کند.
- محتوایی که کاربر صریحاً با «ذخیره در یادداشت» ذخیره کرده، یادداشت مستقل اوست و با بستن چت حذف نمی‌شود. این انتشار تاریخچهٔ چت نیست.
- تاریخچه‌های قدیمی قبل از این نسخه خودکار بازیابی نمی‌شوند؛ سیاست نگهداری قبلی آن‌ها برقرار است. این نسخه حذف سراسریِ تاریخچهٔ همهٔ کاربران یا نسخه‌های پشتیبان قدیمی را اجرا نمی‌کند.
- OpenAI با `store=false` فراخوانی می‌شود و هیچ شناسهٔ مکالمهٔ ذخیره‌شدهٔ ارائه‌دهنده استفاده نمی‌شود. مطابق [راهنمای رسمی کنترل دادهٔ OpenAI](https://developers.openai.com/api/docs/guides/your-data)، این تنظیم به‌تنهایی تضمین Zero Data Retention یا حذف لاگ‌های ارائه‌دهنده نیست. سیاست‌های سایر برندها و نسخه‌های پشتیبان نیز جدا هستند؛ پاک‌شدن از اپلیکیشن را نباید حذف از همهٔ سامانه‌های بیرونی توصیف کرد.

## تست و انتشار

نتایج محلیِ اجراشده روی بستهٔ نامزد:

- ۶۳۷ تست واحد سرویس و ۴۰ تست ابزار انتشار موفق بودند؛ Ruff، Mypy و Bandit بدون خطا و بودجهٔ CSP بدون `onclick` یا `style` inline بود.
- مرورگر واقعی با پایگاه داده، worker و SSE واقعی، سه ارائه‌دهندهٔ مصنوعی، هشت زبان و چهار عرض صفحه موفق بود. درخواست مفصل فرصت/ریسک، ادامهٔ سؤال در همان چت، بسته‌شدن حین تولید پاسخ و بسته‌شدن قبل از رسیدن درخواست ایجاد به سرور آزموده شدند؛ درخواست دیررس پاسخ ۴۱۰ گرفت و کار پولی جدید ایجاد نشد.
- تست SQL، پاک‌شدن متن و snapshot، حفظ دفتر مصرف و رزرو، انقضای lease، tombstone و عدم تمدید idle login با heartbeat را تأیید کرد. بازکردن مجدد پنجره نه پیام قبلی داشت و نه پیش‌نویس.
- آزمون مستقل Report شامل ۸۴ بررسی مرورگری در هشت زبان و ۴۵ بررسی SQL/سرویس موفق بود؛ هیچ داده یا کلید زنده استفاده نشد.
- تصاویر فارسی دسکتاپ/موبایل و انگلیسی برای بازبینی ظاهر تولید و بررسی شدند. دادهٔ تصاویر کاملاً مصنوعی است؛ تغییر مستقیم `lang` در تست چت برای ارزیابی همین مؤلفه است، نه معیار ترجمهٔ بخش‌های قدیمی صفحه.

این شواهد محلی‌اند؛ پذیرش انتشار وابسته به گیت‌های جداگانهٔ CI همان commit است. تست مصنوعی تضمین کیفیت همهٔ پاسخ‌های مدل‌های واقعی نیست و هیچ درخواست پولی به مدل زنده برای این آزمون‌ها ارسال نشد.

تغییر ساختار پایگاه داده، کلیدها، مدل‌ها، مجوز کاربران، زمان‌بندی یا منابع لازم نیست. انتشار فقط پس از موفقیت همهٔ گیت‌های CI و تأیید digest امضاشده انجام می‌شود و فقط سرویس Researcher را جایگزین می‌کند؛ فایل‌های خصوصی و مجوزهای Report حفظ می‌شوند.
