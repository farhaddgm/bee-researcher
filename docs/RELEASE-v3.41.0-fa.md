# Bee Researcher 3.41.0 — پرتال گزارش خصوصی

تاریخ: ۲۰۲۶-۱۰-۱۰. وضعیت فعلی این یادداشت: توسعه انجام شده؛ تأیید/انتشار production هنوز ثبت نشده است.

مسیر جدید `/report`، ورود مشترک User، کنترل مستقل بیزینس/پروژه، پیش‌نویس، نسخهٔ تغییرناپذیر، تحلیل خصوصی، رضایت provider و حذف امن اضافه شده‌اند. [شرح کامل و راهنمای استفاده](REPORT-PORTAL-IMPLEMENTATION-fa.md).

## شواهد اجرا

- آزمون کامل service پس از یکپارچه‌سازی توسعهٔ هم‌زمان ۳٫۴۰٫۲: ۶۳۲ تست واحد موفق، شامل جریان امضاشدهٔ OAuth Report، ثبت درست تلاش ورود سه پرتال و عدم نشت خطای worker. تاریخچهٔ ورود و ساده‌سازی فرم نسخهٔ ۳٫۴۰٫۲ حفظ شده‌اند.
- آزمون ابزار انتشار: ۴۰ تست موفق؛ از جمله کنترل mount خصوصی، rollback بدون حذف گزارش‌ها و اعتبارسنجی امضا بدون bypass.
- تصویر ساخته‌شده، PostgreSQL تازه و نقش runtime محدود: ۴۵ بررسی API موفق؛ شامل جداسازی شرکت‌های هم‌نام، رمزنگاری، CSRF، immutability، idempotency، quota، budget، لغو consent/grant، تعویض بیزینس، cutoff شبانه و tombstone پس از restore.
- مرورگر واقعی: ۵۶ بررسی موفق، هشت زبان و نمای موبایل RTL/LTR، مسیر ورود ← draft ← preview ← worker ← result، نمایش افق اثر و اطمینان مدل، سیاست AI مدیر، پاک‌سازی محتوای نشست پس از خروج و ورود حساب دوم؛ خطای JS مشاهده نشد. گیت دسترس‌پذیری خودکار صفحه نیز موفق بود.
- Ruff، Mypy کل app (۸۹ فایل) و Bandit کل کد اجرایی موفق بودند؛ صحت نحوی JS و بودجهٔ صفر event/style attribute inline نیز موفق بودند.
- رگرسیون گستردهٔ تصویر برای Admin/User، چت/SSE/بودجه/نشست، پشتیبانی، Media/Topic، هشت زبان، دسترس‌پذیری خودکار هر ۱۲ view و startup واقعی با نقش‌های محدود موفق شد. provider واقعی فراخوانی نشد.

همهٔ fixtureها ساختگی‌اند؛ شبکهٔ آزمون داخلی است و AI واقعی/تلگرام یا دادهٔ شرکت واقعی مصرف نشده است. موفقیت ساختاری/مرورگری جای ارزیابی انسانی همهٔ متن‌ها، ورود Google واقعی هر حساب یا کیفیت همهٔ مدل‌های واقعی را نمی‌گیرد.

## موارد عمداً خارج از نسخه

آپلود فایل/صوت، چت گزارش خصوصی، عمومی‌سازی محتوا، ایمیل شرکتی خارج از قرارداد Gmail فعلی، تغییر MFA، و توسعهٔ WhatsApp اضافه نشده‌اند. محدودیت‌های provider و بکاپ در راهنمای پیاده‌سازی شفاف‌اند؛ ادعای نگهداری صفر یا گواهی امنیت مطرح نمی‌شود.
