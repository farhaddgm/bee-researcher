# Bee Researcher 3.40.2

دو عبارت «ورود به Bee Researcher» و «فقط حساب‌های مجاز می‌توانند وارد شوند.»
از فرم مشترک ورود Admin و User و ترجمه‌های آن حذف شدند.

مالک در Settings، جدول گزارش ورود کاربران را می‌بیند: ایمیل، تاریخ و ساعت،
نتیجهٔ موفق یا ناموفق، روش ورود، بخش مقصد و دلیل شکست. هر صفحه حداکثر
۱۰ ردیف دارد و جدیدترین تلاش‌ها ابتدا نمایش داده می‌شوند. مجوز مالک در API
نیز بررسی می‌شود؛ داشتن نقش مدیر پروژه به‌تنهایی اجازهٔ دریافت گزارش نمی‌دهد.

تلاش‌های ورود گوگل بعد از اعتبارسنجی امضا و هویت، پیش از اعمال فهرست مجاز،
قابل ثبت‌اند؛ ایمیل حساب ردشده نیز نگه داشته می‌شود. ورود با رمز عبور، حساب
غیرفعال، فقدان مجوز User و محدودیت تعداد تلاش‌ها هم ثبت می‌شوند. لغو ورود یا
خرابی جریان گوگل پیش از دریافت هویت، ایمیل قابل‌اعتماد در اختیار سرویس نمی‌گذارد
و گزارش برای آن ایمیل خالی نشان می‌دهد.

اطلاعات در جدول موجود و فقط‌افزودنی security_events ذخیره می‌شود؛ نیاز به
مهاجرت دیتابیس یا تغییر مجوزهای runtime نیست. ایمیل در لاگ برنامه و اعلان‌های
عمومی نوشته نمی‌شود و تاریخچهٔ جدید با حذف حساب باقی می‌ماند. لاگ‌های قدیمی
موجود هم بدون تکرار نمایش داده می‌شوند؛ ایمیل ردشدگان قدیمی که قبلاً ذخیره
نشده است، قابل بازسازی نیست.

اعتبارسنجی: ۶۲۱ تست واحد، آزمون واقعی PostgreSQL/API و جریان امضاشدهٔ Google
OIDC همراه با PKCE/state، و آزمون مرورگر مخصوص گزارش ورود. آزمون SQL ذخیرهٔ
ایمیل خارج از فهرست مجاز، سابقهٔ حساب حذف‌شده، نتایج نهایی صحیح، محدودیت
۱۰ ردیف، بازیابی تاریخچهٔ قدیمی و جلوگیری از نمایش تکراری را بررسی می‌کند.
آزمون مرورگر نمایش در هشت زبان و چهار عرض، دکمه‌های قبلی/بعدی/بازخوانی و
عدم دسترسی غیرمالک را می‌سنجد. بررسی CSP و کاتالوگ زبان نیز برقرار است.

برای انتشار از همان PR و گردش امضای ایمیج اصلی استفاده شود. این نسخه
اسکیما، نشست‌های موجود و فهرست مجاز را تغییر نمی‌دهد.
