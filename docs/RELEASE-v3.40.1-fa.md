# نسخهٔ ۳٫۴۰٫۱ — گفتگوی خبر، قابلیت عمومی پرتال User

تاریخ: ۲۰۲۶-۱۰-۱۰. این تغییر طبق درخواست مالک، محدودیت پروژه‌ایِ چت را برمی‌دارد.

- چت برای همهٔ پروژه‌های فعلی و آینده، بدون فعال‌سازی جداگانهٔ پروژه یا اضافه‌کردن شناسه به فهرست مجاز، قابل استفاده است.
- تنظیم فعال/غیرفعال، برند/مدل تأییدشده، بودجه و تعداد درخواست فقط در سطح سرویس/حساب باقی می‌ماند. انتخاب پروژه و بودجهٔ پروژه از فرم تنظیمات چت حذف شده است.
- مجوز مستقل حساب چت و دسترسی به پرتال حفظ می‌شود. عمومی‌بودن قابلیت به معنی اجازهٔ ورود یا خواندن خبرهای پروژه‌های دیگر نیست؛ خبر باید منتشرشده و برای همان حساب قابل مشاهده باشد.
- سقف روزانهٔ عمومی و سقف هر کاربر همچنان به‌صورت اتمی، میان تمام پروژه‌ها مشترک‌اند؛ تغییر پروژه بودجه یا تعداد درخواست را بازنشانی نمی‌کند.
- سیاست‌های JSON قدیمی خوانده می‌شوند، اما دیگر نمایش چت را به یک پروژه محدود نمی‌کنند. در اولین ذخیرهٔ فرم مالک، تنظیمات پروژه‌ای قدیمی پاک می‌شوند؛ مهاجرت دیتابیس و حذف گفتگو لازم نیست.
- به جای مخفی‌شدن بی‌توضیح، خاموش‌بودن سرویس، نداشتن مجوز حساب یا آماده‌نبودن مدل با پیام روشن در هشت زبان نمایش داده می‌شود. در حالت غیرفعال، فرم ارسال پنهان است و خواندن خبر همچنان کار می‌کند.
- هیچ منبع، موضوع، زمان‌بندی، کانال، خبر واقعی، مدل تحلیل خبر یا حساب دیگری تغییر نمی‌کند. فعال‌سازی برندهای جدید و اعطای دسترسی به سایر کاربران جزو این تغییر نیست.

## پذیرش لازم

آزمون کد، گیت‌های امنیت/نوع، سناریوی پروژهٔ ساخته‌شده پس از ذخیرهٔ سیاست عمومی، رد پروژهٔ غیرمجاز، نمایش توضیح در دسکتاپ/موبایل و هشت زبان، سهمیهٔ مشترک و نمایش پنل روی خبرهای واقعیِ مجاز بررسی شوند. نتایج انتشار و آزمون زنده در رسید مستقل ثبت می‌شوند؛ این یادداشت ادعای استقرار انجام‌شده ندارد.
