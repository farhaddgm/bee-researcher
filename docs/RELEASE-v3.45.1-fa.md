# Bee Researcher 3.45.1 — تکمیل پنجرهٔ مطالعهٔ خبر

این اصلاح ادامهٔ PR شمارهٔ ۲۰ است و روی نسخهٔ منتشرشدهٔ ۳٫۴۵٫۰ اعمال می‌شود؛ قابلیت‌های صوت، حافظهٔ خصوصی پروژه و فضای پژوهش حذف یا بازنویسی نمی‌شوند.

## نتیجهٔ مورد انتظار

- توضیح زمینه و سقف روزانه زیر راهنمای `i` کنار عنوان گفت‌وگو است؛ دکمهٔ پرسش دربارهٔ پاراگراف انتخاب‌شده وجود ندارد.
- بخش‌های آمادهٔ فرصت و ریسک از متن User و زمینهٔ چت حذف می‌شوند؛ پیام اصلی تلگرام و اطلاعات Admin دست‌نخورده می‌مانند. دکمه‌های فرصت و ریسک درخواست تحلیل مفصل می‌فرستند و پرسش بعدی در همان گفت‌وگو ادامه می‌یابد.
- تشخیص بخش‌های تولیدشده قبل از تخت‌کردن HTML انجام می‌شود. عنوان مخفی، ترتیب متفاوت بلوک‌ها و ایموجی سفارشی در هشت زبان پوشش دارند؛ تیتر یا خلاصهٔ واقعی با عبارت `Risk:` اشتباهاً حذف نمی‌شود.
- قرارداد API نسخهٔ فعلی، متنِ معمولی است. Reader دیگر آن متن، نام منبع و نمونه‌کد دارای `<`، `>` و `&` را با `innerHTML` تفسیر نمی‌کند. متن خبر، زمینهٔ AI و کلید تشخیص تکرار با یکدیگر سازگار می‌مانند.
- چت ذخیره‌نشده با بستن پنجره پاک و کار در حال اجرا لغو می‌شود؛ پیش‌نویس و تاریخچهٔ آن در پنجرهٔ بعدی بازیابی نمی‌شوند. نشانگر close-before-create و lease کوتاه برای درخواست دیررس، قطع شبکه و بسته‌شدن tab حفظ می‌شوند.
- ذخیرهٔ صریح در «حافظهٔ پروژه» یا «یادداشت»، قابلیت مستقلِ نسخه‌های جدید است و با بستن پنجره حذف نمی‌شود. ذخیرهٔ خودکار چت اضافه نشده است.

## محدودیت حریم خصوصی

پاک‌سازی، متن و snapshot چت ذخیره‌نشده را از ذخیره‌سازی عملیاتی برنامه حذف می‌کند؛ دفتر مصرفِ بدون متن برای سهمیه و هزینه باقی می‌ماند. پاک‌سازی ارائه‌دهندهٔ AI یا پشتیبان‌های قدیمی ضمانت نمی‌شود. `store=false` در OpenAI طبق [راهنمای رسمی کنترل داده](https://developers.openai.com/api/docs/guides/your-data) به‌تنهایی Zero Data Retention نیست.

## پذیرش و انتشار

تست‌های واحد، کیفیت کد، SQL و مرورگر واقعی باید روی ترکیب نهایی با صوت، حافظه، پژوهش و Report اجرا شوند. سناریوی متن فنیِ escape‌شده و فرصتِ قرارگرفته قبل از عنوان به دادهٔ مصنوعی مرورگر اضافه شده است. نتیجهٔ واقعی تست‌ها در گزارش انتشار ثبت می‌شود؛ هیچ تست مصنوعی تأیید کیفیت تمام پاسخ‌های مدل‌های زنده نیست.

پیش از CI، ۶۷۱ تست واحد سرویس و ۴۳ تست ابزار انتشار موفق شدند. Ruff و Mypy بدون خطا بودند؛ آزمون‌های مرورگری/SQL و امضای تصویر، همچنان شرط جداگانهٔ انتشار همین commit هستند.

این نسخه migration، تغییر نقش، کلید، مدل مجاز، بودجه یا زمان‌بندی ندارد. انتشار فقط بعد از گیت‌های اجباری CI، تأیید تصویر امضاشدهٔ همان commit و تعویضِ فقط سرویس Researcher انجام می‌شود؛ فایل‌های خصوصی صوت و Report و تنظیمات زنده حفظ می‌شوند.
