# Bee Researcher 3.47.0

چهار قابلیت در یک انتشار: رصد اصلاح خبر با شواهد تغییر و بازبینی وابستگی‌ها؛ جلسهٔ قابل ویرایش، ذخیره و اشتراک گزینشی؛ صندوق سؤال و پاسخ انسانی با همکار مجاز؛ منتقد تحلیل با هدف صریح و شواهد محدود.

راهنمای استفاده و محدودهٔ دقیق در [راهنمای چهار قابلیت](READER-TOOLS-1-7-9-4-fa.md) است. آزمون‌های واقعی HTTP، PostgreSQL، worker، SSE و مرورگر با حساب‌ها و ارائه‌دهنده‌های مصنوعی، اشتراک، مجوز، رقابت، ذخیرهٔ دیرتر، حریم خصوصی، هشت زبان و چهار عرض را بررسی می‌کنند.

0050 افزایشی است؛ migration و اتصال کارهای ذخیره‌شدهٔ قبلی پس از بکاپ خصوصی و تأیید مستقل بستهٔ امضاشده اجرا می‌شوند. رمز، نقش اعضا، رضایت کسب‌وکار، کلیدها و سرویس‌های دیگر حفظ می‌شوند.
