# Bee Researcher 3.41.1 — اصلاح فهرست خبر و عملیات رابط کاربری

در فهرست خبرها، سرستون انتخاب گروهی وجود داشت اما ساخت چک‌باکس ردیف به `onclick` قدیمی وابسته بود. پس از مهاجرت CSP، عنوان خبر در ستون ۴۴ پیکسلی انتخاب قرار می‌گرفت و وضعیت انتشار جای ستون خبر را می‌گرفت. ردیف اکنون شناسهٔ مستقل دارد و هر هفت ستون با سرستون خود هم‌تراز است. عنوان، وضعیت و نام منبع داخل سلول خود می‌مانند و متن طولانی می‌شکند.

نوار عملیات گروهی فقط یک بار ساخته می‌شود. انتخاب همه، انتخاب جزئی، صفحه‌بندی، فیلتر و حالت خالی هماهنگ‌اند. انتخاب‌ها و امکان بازگردانی هنگام تغییر حساب یا پروژه پاک می‌شوند؛ پاسخ دیرهنگام عملیات پروژهٔ قبلی وضعیت پروژهٔ جدید را تغییر نمی‌دهد.

دکمهٔ بیزینس فعال اکنون درخواست غیرفعال‌سازی می‌فرستد. فعال‌سازی مجدد نیز با همان مجوزهای API انجام می‌شود؛ هر دو از اتصال رویداد سازگار با CSP استفاده می‌کنند. دادهٔ دکمهٔ ویرایش نیز برای ویژگی HTML به‌درستی escape می‌شود؛ نام و توضیح دارای کوتیشن، علامت & و متن شبیه HTML بدون شکستن رویداد یا اجرای HTML در فرم باقی می‌مانند.

اعتبارسنجی محلی شامل ۶۳۲ تست واحد، مجموعه‌های مرورگر ادمین/کاربر/حساب/پشتیبانی/رسانه/تنظیمات/کانتکست تحقیق/گزارش ورود/Contenter/دسترس‌پذیری، آزمون‌های واقعی PostgreSQL و ورود Google امضاشده با state و PKCE، و پذیرش مستقل گزارش خصوصی و گفت‌وگوی خبر بود. ماتریس پنل ۸ زبان × ۴ عرض × ۱۲ صفحه و آزمون جدید خبر ۸ زبان × ۴ عرض × ۲ تم اجرا شدند. اتصال Contenter با HTTPS و گواهی مورد اعتماد در محیط جدا آزمایش شد. مرزهای ارائه‌دهندگان AI، Google و Telegram با داده یا سرویس مصنوعی آزموده شدند.

آزمون `admin:news:e2e` به گیت اجباری CI افزوده شده است. انتشار از ایمیج امضاشدهٔ main پس از موفقیت گیت‌ها انجام می‌شود؛ این نسخه migration جدید ندارد.
