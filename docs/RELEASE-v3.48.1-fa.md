# Bee Researcher 3.48.1

نسخهٔ نهایی سهمیه‌های چهارگانهٔ توکن و گزارش خصوصی مصرف. تعداد ورودیِ اعلام‌نشده یا نامعتبر در Anthropic صفر فرض نمی‌شود؛ رزرو و برآورد تا دریافت شمارش معتبر حفظ می‌شوند. فیلدهای اختیاری cache فقط در صورت نبودن، صفرند؛ قیمت وزن‌دار cache از شمارش خام توکن جداست.

پیش‌فرض عمومی، پیش‌فرض پروژه و استثنای کاربر در همان پروژه، فقط برای مالک ایمیل تنظیم‌شده قابل تغییرند. گزارش مصرف همهٔ کاربران Reader در تنظیمات در دسترس است. schema افزایشی 0051 و نقش محدود اجرا پیش از نصب جداگانه تأیید می‌شوند. سقف‌های اولیه نامحدودند تا مالک اعداد را انتخاب کند؛ مصرف قبلی حفظ می‌شود.

دو آزمون Native protocol برای ورودی مفقود، Boolean، ورودی منفی و cache نامعتبر، به مجموعهٔ اعتبارسنجی اضافه شدند. آزمون‌ها مصنوعی و بدون فراخوانی پولی هستند.
